# 《我的大学四年》结尾动画：星尘汇流设计说明

## 状态

- 日期：2026-08-19
- 范围：文章结尾的 `graduation-achieved` shortcode 动画
- 设计状态：已完成视觉方向确认，待用户复核书面说明

## 背景与问题

文章最后并不是在宣布一个游戏成就，而是在回望一段不会重来的大学生活：有遗憾、有想念，也有继续生活的准备。现有动画使用“ACHIEVEMENT UNLOCKED”、学士帽、硕士帽、环形进度和火焰拖尾，动作较强，叙事重点落在“升级”和“解锁”上，与正文收束时的克制情绪不一致。

本次重设计将动画从“成就升级”改成“记忆汇流后的告别”。它只服务于文章结尾，不新增音频、点击操作或其他页面功能。

## 已确认的设计决策

1. 采用“星光汇流”作为整体视觉方向。
2. 星光保持抽象，不使用文章中的真实照片或地点图片。
3. 使用正文最后一句作为最终收束文案：

   > 因为那个暑假，以后大概真的不会再有了。

4. 动画在滚动进入视口后自动播放一次，结束后保持静止。
5. 不再使用成就弹窗、学士帽、硕士帽、火焰拖尾、环形进度或 `BACHELOR → MASTER` 文案。
6. 必须支持亮色主题、暗色主题、移动端和 `prefers-reduced-motion`。

## 体验目标与非目标

### 体验目标

- 让读者感到四年里的零散记忆在结尾处被轻轻收拢。
- 给正文最后一句留出足够的停顿和阅读时间。
- 视觉有记忆点，但不抢走文章本身的情绪。
- 在没有动画能力或读者主动减少动态效果时，仍然完整呈现最终文案。

### 非目标

- 不模拟游戏成就、学位升级或任务完成。
- 不制作复杂的 3D 星空、随机宇宙背景或高成本粒子系统。
- 不引入图片、字体、第三方动画库或音频资源。
- 不改变文章正文内容、主题布局或其他文章的 shortcode 行为。

## 动画叙事与时间线

整个动画约 5.8 秒。所有时间均为进入播放状态后的相对时间。

| 时间 | 画面 | 叙事作用 |
| --- | --- | --- |
| 0–0.7 秒 | 只有稀疏、低亮度的星点 | 先让结尾安静下来 |
| 0.7–2.5 秒 | 星点从不同方向缓慢进入，轨迹略有差异 | 表现四年里零散的人、夜晚和经历 |
| 2.5–3.8 秒 | 星点向中央汇流，组成不规则的小型星群 | 让记忆形成一个短暂的共同焦点 |
| 3.8–4.5 秒 | 星群短暂变亮，出现细小星芒 | 提供情绪停顿，不做爆发式冲击 |
| 4.5–5.8 秒 | 星芒向上方缓慢漂移，最终文案从低亮度提升到完整亮度 | 从回望过渡到告别 |
| 5.8 秒后 | 星点和文案保持静止 | 让读者可以完整读完最后一句 |

星点不做无限循环。结束状态可以保留非常轻微的静态光晕，但不能持续闪烁或持续位移。

## 视觉系统

### 容器

- 动画区域继续嵌入文章正文，不使用厚重卡片或独立弹窗。
- 背景继承页面底色，只叠加低强度的蓝灰色径向渐变。
- 动画区域保持居中，并为最后一句保留稳定的垂直空间，避免播放时造成文章布局跳动。

### 星光

- 主色为冷白和浅蓝，中央汇流时加入少量温暖米黄色。
- 星点尺寸和透明度有小幅差异，但位置与轨迹固定，保证每次播放一致。
- 中央星群由少量星点和细线构成不规则形状，不使用圆环或仪表盘隐喻。
- 光晕保持柔和，避免强烈霓虹、爆炸、火焰或游戏 UI 质感。

### 文案层级

- 顶部仅保留小号时间标记：`2022 — 2026`。
- 最终文案是唯一的主视觉文字，沿用主题可读的中文字体风格。
- 不再显示英文成就标题或学位转换说明。

## 组件结构与职责

实现仍拆分为 shortcode、CSS 和 JavaScript 三层，保持现有资源加载方式不变。

### Shortcode 模板

文件：`layouts/shortcodes/graduation-achieved.html`

- 输出唯一的动画根节点和可读的最终文案。
- 提供背景层、固定星点层、中央星群层和文案层。
- 装饰性星点和线条使用 `aria-hidden="true"`。
- 保留页面级资源只加载一次的逻辑。

### 样式

文件：`assets/css/graduation-achieved.css`

- 使用状态类控制准备、播放和结束状态。
- 主要动画属性限定为 `transform`、`opacity` 和少量 `filter` 光晕。
- 通过主题选择器调整亮色和暗色下的对比度，而不改变构图。
- 使用媒体查询适配窄屏布局。
- 删除现有环形进度、帽子、冲击圈和火焰拖尾相关样式。

### JavaScript

文件：`assets/js/graduation-achieved.js`

- 继续使用 `IntersectionObserver`，进入视口后只触发一次并解除观察。
- 在开始观察前标记动画已准备，避免没有 JavaScript 时文案被隐藏。
- 保持多个 shortcode 实例互不影响。
- 不生成随机轨迹，不依赖外部库，不在每一帧执行脚本。

## 状态与降级行为

动画需要有明确的静态可用状态：

1. **静态状态**：无 JavaScript、尚未触发或浏览器不支持观察器时，最终文案以较低亮度但可读的状态显示，装饰星群保持可见或以静态形式呈现。
2. **准备状态**：JavaScript 已初始化，动画元素等待进入视口；文案继续保持可读，播放时再从低亮度提升到完整亮度，避免脚本加载失败造成空白。
3. **播放状态**：添加播放状态类，按时间线执行一次星点汇流和文案淡入。
4. **结束状态**：动画停止在可读的星群和最终文案上，不循环。
5. **减少动态效果**：不执行位移、汇流和闪烁，直接展示最终星群、时间标记和文案。

## 响应式与无障碍

- 桌面端使用约 360–680px 的居中舞台，星群和文案共享稳定的内容宽度。
- 移动端缩小星群活动范围，保持最终文案的字号、行高和换行可读。
- 装饰元素不进入屏幕阅读器阅读顺序。
- 最终文案保留在真实 DOM 中，不依赖伪元素生成。
- 光晕和颜色不作为唯一信息来源，动画结束后文字仍能独立表达结尾。

## 验证标准

实现完成后至少验证以下场景：

- Hugo 构建成功，短代码资源路径和指纹资源正常。
- 首次滚动进入视口时播放一次，离开视口再回来不会重复播放。
- 动画播放期间文章正文不发生明显布局跳动。
- 桌面窄窗口和约 375px 宽移动端均能看到完整文案。
- 亮色和暗色主题下星点与文案都有足够对比度。
- 浏览器不支持 `IntersectionObserver` 时仍能看到最终文案。
- 开启系统“减少动态效果”时不出现明显位移或闪烁。
- JavaScript 未加载时，页面仍能显示最终文案。
- `git diff --check` 无空白错误，变更只涉及结尾动画相关文件和设计说明。

## 方案取舍记录

- **游戏成就升级**：保留了清晰的动作反馈，但会把文章结尾导向“获得学位/升级”，与正文的私人回望不符，因此移除。
- **真实照片拼贴**：纪念感强，但会重复文章已有图片，也会让动画依赖图片加载和布局，最终选择抽象星光。
- **银河长镜头**：电影感更强，但视差和持续背景运动更复杂，且容易把情绪做得过于宏大，因此不作为第一版。
- **极简片尾字幕**：最安全克制，但缺少“记忆汇流”的动作叙事，因此选择保留星点汇聚这一核心动作。

## 完成定义

当结尾动画完成以下条件时视为达到本设计目标：读者能在不看到游戏化元素的情况下感受到“零散记忆被收拢后，安静地告别一个不会重来的暑假”；最终文案始终可读；动画在不同主题、移动端、无脚本和减少动态效果环境下均有合理静态结果。
